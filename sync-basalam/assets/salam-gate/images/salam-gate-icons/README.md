# Gentlecons icons used by Salam Gate / آیکون‌های سلام‌گیت

[English](#english) · [فارسی](#فارسی)

## English

Icons by **Konstantin Filatov**, from **Gentlecons Interface Icons**, distributed
under **Creative Commons Attribution 4.0 International (CC BY 4.0)**.

- [Collection](https://www.svgrepo.com/collection/gentlecons-interface-icons/)
- [Author](https://www.svgrepo.com/author/Konstantin%20Filatov/)
- [SVG Repo licensing](https://www.svgrepo.com/page/licensing/)
- [License](https://creativecommons.org/licenses/by/4.0/)
- Per-icon original download URLs and IDs: [manifest.json](manifest.json).

Changes: removed export comments and fixed dimensions, replaced fixed fills with
`currentColor`, and marked icons as decorative. Geometry is unchanged. The truck
in `../salam-gate-truck.svg` uses the same geometry with an orange fill for the
existing loader. The sidebar truck inherits the menu's text color.

The bundled SVGs are served locally. `../../styles/salam-gate-icons.css` maps
existing decorative Dashicons and inline SVG containers to these assets using
CSS masks, preserving button labels, accessibility names, semantic colors and
the shared form's JavaScript contracts. Loading truck containers keep their
existing animation and reduced-motion behavior.

## فارسی

این آیکون‌ها اثر **Konstantin Filatov** از مجموعه **Gentlecons Interface Icons** و با مجوز **CC BY 4.0** هستند. لینک مجموعه، نویسنده و متن مجوز در بخش بالا و شناسه/URL اصلی هر آیکون در [manifest.json](manifest.json) حفظ شده‌اند.

تغییرات شامل حذف توضیح export و ابعاد ثابت، تبدیل fill به `currentColor` و علامت‌گذاری تزئینی است؛ هندسه تغییر نکرده. `../salam-gate-truck.svg` همان هندسه کامیون با نارنجی برای لودر است و کامیون منو رنگ متن را می‌گیرد.

فایل‌ها محلی سرو می‌شوند. `../../styles/salam-gate-icons.css` با CSS mask آیکون تزئینی را جایگزین می‌کند؛ متن دکمه، نام دسترس‌پذیر، رنگ معنایی و قرارداد JavaScript فرم حفظ می‌شوند. موشن لودر و ترجیح کاهش حرکت باقی است. این فایل دو‌زبانه و manifest عمداً برای حفظ انتساب در بسته قرار دارند؛ فایل مجوز را حذف نکنید.
